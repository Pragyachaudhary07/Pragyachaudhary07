### 🚀 Featured Projects

#### 🌱 [AI-Powered Carbon Footprint Tracker](https://github.com/Pragyachaudhary07/AI-Powered-Carbon-Footprint-Tracker)

A Flask web application that estimates a person's daily carbon footprint (kg CO₂/day) from travel, energy, diet and waste habits using a trained Random Forest regression model.

- 🤖 **ML inference API** — `RandomForestRegressor` (R² ≈ 0.93) predicts emissions from 8 daily-habit inputs and returns a Low / Medium / High category with a tailored eco tip
- 🔐 **Google Sign-In** with Flask-Dance (OAuth 2.0) and Flask-Login; guests can still use the calculator without an account
- 📈 **Per-user analytics** — prediction history, category breakdown, 7-day trend and summary endpoints, isolated per user at the database query level
- 🗄️ **Data layer & deployment** — Flask-SQLAlchemy with PostgreSQL (SQLite locally), Alembic migrations and a Render deployment blueprint

#### 🏥 [Hospital Management System](https://github.com/Pragyachaudhary07/-Hospital-Management-System-)

A role-based hospital management application that organises patients, doctors, appointments and treatment records in one centralised Flask system.

- 👥 **Three role-based portals** — separate admin, doctor and patient dashboards built as modular Flask Blueprints
- 📅 **Appointment workflow** — patients book and cancel appointments against doctor availability; doctors and admins manage the schedule
- 🩺 **Treatment records** — doctors record diagnosis, prescription and notes per appointment and can view a patient's full history
- 🔎 **Admin tools** — add, update and remove doctors, view patients, and search records using SQLAlchemy queries

#### 😊 [Facial Emotion Recognition](https://github.com/Pragyachaudhary07/facial-detection)

A real-time facial expression recognition system that detects faces from a webcam feed and classifies seven emotions with a convolutional neural network.

- 🧠 **CNN classifier** built in Keras (Conv2D, BatchNormalization, Dropout) for 7 emotions: angry, disgust, fear, happy, neutral, sad and surprise
- 📷 **Face detection** with an OpenCV Haar cascade classifier on live video frames
- ⚙️ **Preprocessing pipeline** — grayscale conversion, 48×48 face crops and normalisation before inference
- 🎥 **Real-time inference** with emotion labels drawn on the webcam stream
